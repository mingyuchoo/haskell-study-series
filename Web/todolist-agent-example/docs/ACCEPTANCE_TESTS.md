# 인수 테스트

## AT-001 Todo 생성

Todo가 없는 상태에서 유효한 제목을 전송하면 상태 코드는 201이고, 응답의 `status=active`, `completedAt=null`이며 Todo가 저장된다.

## AT-002 빈 제목 거부

공백 문자만으로 이루어진 제목을 전송하면 오류 코드 `INVALID_TITLE`과 함께 400을 반환하고, 아무것도 저장되지 않는다.

## AT-003 목록 순서

Todo A가 Todo B보다 먼저 생성되었으면 목록 조회는 A를 B보다 앞에 반환한다.

## AT-004 완료

활성 Todo를 완료하면 200을 반환하고 상태는 completed가 되며 `completedAt`은 null이 아니다.

## AT-005 멱등적 완료

이미 완료된 Todo를 다시 완료해도 200을 반환하고 최초 완료 시각은 변경되지 않는다.

## AT-006 존재하지 않는 Todo

존재하지 않는 유효한 UUID를 조회하거나 완료하면 404를 반환한다.

## AT-007 삭제

존재하는 Todo를 삭제하면 204를 반환하고, 이후 조회는 404를 반환한다.
