# 제품 명세

## 목표

TodoList는 한 명의 사용자가 할 일을 기록하고 활성 또는 완료 상태를 관리할 수 있게 한다.

## 핵심 기능

1. 필수 제목과 선택적 설명으로 Todo를 생성한다.
2. 모든 Todo를 오래된 순서대로 조회한다.
3. ID로 Todo를 조회한다.
4. 활성 Todo를 완료한다.
5. Todo를 삭제한다.

## 비즈니스 규칙

- 제목은 검증 및 저장 전에 앞뒤 공백을 제거한다.
- 제목에는 공백이 아닌 문자가 하나 이상 있어야 한다.
- 제목의 최대 길이는 유니코드 코드 포인트 200개이다.
- 새 Todo의 상태는 `Active`이며 완료 시각은 없다.
- 이미 완료된 Todo를 다시 완료해도 성공하며 상태는 변하지 않는다(멱등성).
- 버전 1에서는 완료된 Todo를 다시 열 수 없다.

## 비목표

- 인증 또는 계정
- 공유
- 태그, 카테고리, 우선순위, 기한, 반복, 알림
- 파일 첨부
- 완료된 Todo 재개방
- 실시간 동기화

## 완료의 정의

기능은 기존 동작을 훼손하지 않으면서 명세, 관련 인수 시나리오, 테스트 및 공개 API 계약을 충족해야 한다.
