# T-20260907-nav-purpose: 성격별 메뉴 구성과 조직 진단 명칭

## 승인된 범위

기존 `조직 현황`을 `조직 진단`으로 변경하고 메뉴를 다음 네 그룹으로 재구성한다.

- 조직 분석: 조직 진단 → 업무 흐름
- 조직 운영: 구성원 → 목표 → 책임 → 권한
- 에이전트 설계: 에이전트 초안
- 운영과 개선: 결과 → 학습 → 활동 기록

## 구현 계획

1. `static/src/Main.elm`의 그룹 이름 및 메뉴 배열을 승인된 순서로 수정한다.
2. `static/src/Page.elm`을 비롯한 진단 화면 이름 표시 위치를 확인해 `조직 진단`으로 일관되게 변경한다.
3. 기존 조직 전환, 그룹 구분선, 메뉴 탐색 및 모바일 구성을 보존한다. 별도 시작 안내나 단계 기능은 추가하지 않는다.
4. 기존 빌드로 `static/app.js`를 재생성하고 `make test` 및 변경 검사를 수행한다.
5. tester가 그룹과 메뉴 순서, 화면 이름의 일관성, 기존 기능 보존 및 검증 결과를 독립 확인한다.

## 수용 기준

- 위 네 그룹 및 메뉴 순서가 정확히 적용된다.
- 메뉴와 진단 화면 제목이 `조직 진단`으로 일치한다.
- 기존 메뉴 목적지와 선택 상태, 조직 전환 및 그룹 구분선이 유지된다.
- 시작 안내 또는 단계 기능이 추가되지 않는다.
- 빌드·테스트 결과와 실제 검증 한계를 보고한다.
