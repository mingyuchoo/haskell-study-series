# T-20260907-nav-divider: 메뉴 그룹 사이 구분선

## 요청과 범위

네 메뉴 그룹 사이에 은은한 가로 구분선을 추가한다. 구현 범위는 `static/style.css`이며 메뉴 순서와 탐색 기능은 유지한다.

## 구현 및 검증 계획

1. 인접 그룹 선택자 `.nav-group + .nav-group`에 기존 사이드바 팔레트의 1px 가로선을 적용한다.
2. 첫 그룹 앞이나 마지막 그룹 뒤에는 선을 추가하지 않고 기존 그룹 간격과 모바일 2열 메뉴를 유지한다.
3. tester가 CSS 선택자, 선 두께 및 색상, 여백과 모바일 규칙을 읽기 전용으로 확인한다.
4. coder가 변경에 맞는 CSS 검사와 기존 테스트를 실행하고 실제 결과 및 환경 제한을 보고한다.

## 수용 기준

- 네 그룹 사이 세 곳에만 은은한 1px 가로선이 나타난다.
- 기존 팔레트를 사용하고 선이 제목 및 메뉴와 겹치지 않는다.
- 기존 메뉴 순서, 그룹 간격 및 모바일 배치가 유지된다.
- 관련 없는 구현 및 의존성 변경이 없다.
