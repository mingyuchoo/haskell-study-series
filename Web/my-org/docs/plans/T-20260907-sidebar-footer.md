# T-20260907-sidebar-footer: 사이드바 하단 안내 제거

## 요청

사용자가 지정한 좌측 사이드바 하단 안내 문구 전체와 초록 점을 제거한다.

## 구현 및 검증

1. `static/src/Main.elm`에서 `.aside-foot` 노드 전체를 제거한다.
2. `.aside-foot` 전용 CSS는 다른 사용처가 없는지 확인한 후 정리한다. 공유 `.dot` 스타일은 다른 화면에서 사용하는 경우 유지한다.
3. 기존 프런트 빌드로 `static/app.js`를 재생성하고 `make test` 및 변경 검사를 실행한다.
4. tester가 안내 노드와 전용 CSS 제거, 공유 점 스타일 보존, 메뉴 및 그룹 구분선 유지 여부를 읽기 전용으로 검증한다.

## 수용 기준

- 사이드바 하단 안내 문구와 해당 초록 점이 표시되지 않는다.
- 기존 메뉴, 조직 전환 및 그룹 구분선은 유지된다.
- 다른 화면의 상태 표시와 공통 스타일에 영향이 없다.
- 빌드와 테스트 결과 및 검증 한계를 보고한다.
