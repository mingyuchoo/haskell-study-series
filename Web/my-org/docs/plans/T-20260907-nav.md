# T-20260907-nav: 조직 메뉴를 사용 절차에 맞게 재구성

## 확인된 요청

사용자는 좌측 메뉴를 앞서 제안한 네 단계로 재구성하도록 승인했다. 조직 목록은 현재 조직 내부의 메뉴에서 분리하여 상단 조직 전환 영역으로 제공한다.

## 구현 계획

1. 기존 좌측 메뉴 구현과 적용되는 하위 규약을 확인하고 기존 경로 및 현재 메뉴 표시 방식을 유지한다.
2. 다음 순서로 그룹 제목과 메뉴를 표시한다.
   - 현황 파악: 조직 현황 → 구성원
   - 업무 설계: 목표 → 업무 흐름 → 책임 → 권한
   - 에이전트 설계: 에이전트 초안
   - 운영과 개선: 결과 → 학습 → 활동 기록
3. 상단 현재 조직 표시 영역에 기존 조직 목록 경로로 이동하는 조직 전환 동작을 제공한다. 조직 미선택 화면도 기존 접근 기능을 유지한다.
4. 기존 디자인과 반응형 구성을 따르며 그룹 제목, 간격, 선택 상태, 키보드 탐색을 확인한다.
5. 변경에 맞는 기존 테스트를 실행하고 tester 검증 및 reviewer 승인을 받는다. `make test`가 없거나 실행할 수 없으면 실제 원인과 대체 검증 결과를 기록한다.

## 수용 기준

- 조직 내부 메뉴 10개가 위의 네 그룹 및 순서로 각각 한 번씩 나타난다.
- 목표가 업무 흐름보다 먼저 나오고 에이전트 초안은 책임과 권한 다음에 나온다.
- 조직 목록은 네 그룹에서 분리되고 상단 조직 전환 영역에서 접근할 수 있다.
- 기존 메뉴 목적지, 선택 상태, 조직별 경로와 접근성 동작이 유지된다.
- 작은 화면에서도 메뉴가 잘리거나 겹쳐 접근 불가능해지지 않는다.
- 테스트 결과와 리뷰 결과가 보고되며 관련 없는 기능이나 의존성을 변경하지 않는다.

## 아직 확인하지 않은 사항

코드 구조, 테스트 명령 및 현재 반응형 동작은 coder의 저장소 조사로 확인한다. 새 조직 선택 화면이나 별도의 드롭다운 구현이 필수라는 요구는 없으므로 기존 조직 목록 이동 동작을 활용한다.
