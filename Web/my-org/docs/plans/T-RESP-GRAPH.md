# T-RESP-GRAPH — 책임 관계 다이어그램

## 확인한 사실
- 책임 화면 하단은 edges를 문자열로 나열한다. 상단 책임 배정 카드/표와 owner-목표ID 포커스 대상은 이미 존재한다.
- Workspace의 people/goals/authorities/edges로 사람·목표·지표·자원과 진단을 표시할 수 있다. 서버 API는 graph.nodes를 생성하지만 현재 Elm Workspace가 edges만 읽으므로 목표 목록을 합쳐 고립 목표도 포함한다.
- DependsOn 방향은 상위 목표 → 하위 목표이다. Metric 이름은 goals의 metric.id/name으로 해석한다.
- 작업 루트 및 관련 static/src/Page, src/MyOrg/Domain, docs/plans에는 별도 AGENTS.md가 없다. 제공된 공통 규약을 적용한다.

## 구현 결정
1. 책임 그래프 전용 Elm 모듈에 순수 노드/연결 정리와 렌더링을 분리한다. 기본은 사람 → 목표 → 지표의 안정적인 열 배치이며 자원은 토글 시 별도 영역에 표시한다. API 및 영속 데이터는 변경하지 않는다.
2. 독립 상태에 다이어그램/관계 목록(기본 다이어그램), 검색어, 하위 목표 표시, 권한·예산 표시, 선택 노드, 확대율을 둔다. 상단 카드/표와 독립적으로 유지하고 조직 변경 시 선택 노드가 다른 조직으로 누출되지 않게 초기화한다.
3. SVG 화살표와 한글 관계명(책임/하위 목표/측정 지표/보유 권한), 노드 유형별 모양 또는 라벨, 지표의 실제 이름, 권한의 한국어 이름을 사용한다. ID가 다른 노드는 이름이 같아도 합치지 않는다. 기존 설치된 elm/virtual-dom 1.0.3을 indirect에서 direct로 분류 변경하고 nodeNS로 실제 SVG 네임스페이스를 생성한다. 오케스트레이터가 승인한 분류 조정이며 새 패키지 추가나 버전 변경은 없다.
4. 노드 클릭 또는 키보드 활성화 시 이웃 관계를 강조한다. 상세 패널에서 사람의 역할·담당 목표, 목표의 책임자·상태·필요 권한·통제율, 지표/자원의 관련 관계를 확인한다. 기존 책임자 지정 owner-ID 폼 및 관련 메뉴로 이동하는 메시지를 재사용한다.
5. 책임자 미지정과 권한 부족(책임자가 있고 coverage < 1)을 텍스트 및 경고 스타일로 구분한다. 고립 목표와 빈 그래프, 검색 결과 없음 상태를 제공한다.
6. 검색 시 일치 노드와 연결 관계를 이해할 수 있는 맥락을 유지한다. 확대·축소와 전체 맞춤을 제공하고, 범위 제한 및 좁은 화면 스크롤을 지원한다. 긴 한국어 목표는 줄바꿈/축약과 전체 이름 상세 표시를 함께 제공한다.
7. 관계 목록은 한글 관계명과 해석된 노드명을 사용한다. 선택/필터와 보기 전환이 기존 책임자 입력 초안을 지우거나 저장 동작을 바꾸지 않아야 한다.

- 보기 독립성, 선택 강조 및 상세 이동, 키보드 활성화, 확대 범위/전체 맞춤, 빈 상태를 확인한다.
- make test 및 프런트 빌드/린트를 실행한다. 브라우저에서 SVG 실제 렌더링, 화살표·긴 이름·모바일 스크롤·선택·필터를 확인한다.
