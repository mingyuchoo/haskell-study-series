# T-DEFAULT-TABLE: 목록 보기 기본값을 표로 통일

## 확인한 사실
- Main.listMode는 메뉴별 선택값이 없을 때 책임만 Table, 나머지는 Cards를 반환한다.
- 조직 목록·구성원·목표·권한·결과·학습의 Page.view 기본 래퍼는 Cards, 책임은 Table이다.
- 메뉴별 선택은 listModes에 저장되며, 책임 관계 그래프는 별도 상태로 관리한다.
- 저장소 루트와 관련 하위 경로에서 AGENTS.md는 발견되지 않아 사용자 제공 규약을 적용한다.

## 구현 계획
1. Main.listMode의 기본값을 모든 메뉴에 Table로 통일한다.
2. 여섯 Page.view 기본 래퍼를 Table로 통일하고 책임의 기존 기본값은 유지한다.
3. 카드 전환, 메뉴별 선택 유지, 그래프 상태 및 기존 입력 상태는 유지한다.
4. 기존 테스트의 카드 기본 전제가 있으면 명시적인 카드 선택으로 수정한다. 빌드, make test 및 관련 검증 후 reviewer와 tester의 승인을 받는다.

## 범위
UI 기본값 변경만 수행하며 새로운 의존성이나 목록 구조 변경은 없다.
