## 이 저장소의 사고 기록에 대하여

사고 문서는 비난 없이 사실, 영향, 탐지, 대응과 시스템 개선을 기록합니다. 반복해서 적용할 교훈은 테스트, 경보, 규칙 또는 `lessons.md`로 공고화합니다.
