# Event Contracts

서비스 간 게시되는 이벤트의 의미와 전달 계약을 저장합니다.

## 현재 상태

게시된 이벤트 계약이 없습니다. 현재 Todo 앱은 단일 프로세스 안에서 동기 호출로만 동작하며 비동기 통신이 필요한 흐름이 없습니다.

이벤트 기반 통신을 도입하려면 먼저 `../../decisions/ADR-0002-effect-boundary.md`를 확인하고, 생산자와 소비자, 전달 보장, 실패 복구 요구를 문서로 정한 뒤 새 ADR을 작성합니다. 필요하지 않은 기반 시설을 미리 만들지 않습니다.

## 새 계약에 포함할 내용

- 이벤트 이름, 소유 생산자와 소비자
- 발생 조건과 비즈니스 의미
- 페이로드 스키마와 버전
- 순서와 중복 가능성
- 전달 보장과 재처리 정책
- 민감 정보 분류와 보존 기간
- 호환성 및 폐기 정책
- 연결된 계약 테스트
