# Data Contract: 이름

- 상태: Draft
- 소유 패키지: 패키지 이름
- 소비자: 소비자 목록
- 버전: v1
- 분류: Public, Internal, Confidential, Restricted 중 하나

## Meaning

데이터 세트 또는 개체의 비즈니스 의미를 설명합니다.

## Schema

필드, 타입, null 가능성, 단위와 제약을 설명합니다. 기계적 사실은 생성 문서를 연결합니다.

## Ownership and Access

쓰기 권한, 읽기 권한과 접근 경계를 설명합니다.

## Lifecycle

생성, 갱신, 보존, 삭제와 익명화 정책을 설명합니다.

## Compatibility and Migration

스키마 진화와 기존 데이터 처리 방식을 설명합니다.

## Verification

스키마 및 데이터 품질 검사 위치를 연결합니다.
