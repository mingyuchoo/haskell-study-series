# Architecture Decision Records

## 상태

- Proposed: 검토 중
- Accepted: 현재 적용되는 결정
- Deprecated: 새 사용을 권장하지 않음
- Superseded: 다른 ADR이 대체함
- Rejected: 검토 후 채택하지 않음
