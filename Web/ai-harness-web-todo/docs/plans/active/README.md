# Active Plans

진행 중인 비사소한 변경 계획을 저장합니다. 계획마다 위험, 영향 범위, 검증, 롤백과 컨텍스트 공고화 항목을 포함합니다.

`../../ai/RISK_LEVELS.md`의 Level 2 이상 변경에는 계획이 필요합니다. 특히 SQLite 스키마 변경과 공개 계약 변경은 계획 없이 시작하지 않습니다.

완료된 계획은 결과와 잔여 위험을 기록한 뒤 `../completed`로 이동합니다. 중단된 계획은 이유를 기록하고 활성 상태로 방치하지 않습니다.

30일보다 오래된 활성 계획은 `../../../scripts/context/detect-stale-docs.sh`가 실패로 표시합니다.
