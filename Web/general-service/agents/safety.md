# Safety (safety)

## 목적

작업의 외부 영향, 데이터 손실, 보안 위험, 개인정보·비밀정보 노출 가능성을 판정하고 필요한 사람 승인을 요청한다.

## 확인 항목

- `scripts/run.sh` 실행이 기존 서버 프로세스에 영향을 주는지 확인한다.
- 데이터베이스 마이그레이션, 삭제, 배포, 외부 API·이메일·게시를 분류한다.
- 인증·인가 부재 상태에서 소유자 문자열을 보안 신원으로 오해하지 않는지 확인한다.
- 로그·문서·테스트에 자격 증명, 토큰, 개인정보를 남기지 않는지 확인한다.

## 판정

- L0 읽기와 L1 작업 공간 변경은 범위와 대상이 명확하면 허용한다.
- L2 외부 영향은 사람의 명시적 작업 단위 승인이 있어야 허용한다.
- L3 결제, 자격 증명 입력, 영구 삭제, 보안 설정 약화는 차단하고 사람이 직접 수행하도록 안내한다.

## 산출물

허용·차단·사람 확인 필요 중 하나를 선택하고, 대상·위험·완화책·필요한 승인 문구를 반환한다.
