## 현재 분석

실행 서버는 Task·Outcome·사용자·세션을 SQLite에 저장하도록 전환되었다. 시작 시 전진 마이그레이션을 적용하고 DB 재개방 뒤 데이터를 검증하는 통합 테스트가 있다. 개발 예시 Task는 `SEED_EXAMPLE_DATA`로 비활성화할 수 있고, 기존 메모리 저장소는 단위 테스트 대역으로 유지한다.

현재 구현은 단일 프로세스의 DB 접근만 직렬화하므로 다중 인스턴스·공유 파일시스템 운영을 지원하지 않는다. 운영 DB에 대한 자동 백업과 복원 훈련은 아직 적용하지 않았다.

## 목표

Task·Outcome·담당자·검토 코멘트를 영속 저장하고, 안전한 초기화와 스키마 변경 절차를 제공한다.
